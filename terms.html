What this is

TheClipDept is a private tool run by one person for their own business. It is not offered to the public and has no user sign-up.

Using TikTok with it

TheClipDept connects to a TikTok account only when the account's owner chooses to connect it, using TikTok's official login. It reads that account's profile, statistics and list of public videos. It does not post, comment, follow or change anything on TikTok.

Use of TikTok remains subject to TikTok's own terms.

Ending the connection

The connection can be removed at any time from within TheClipDept, or from the app permissions in TikTok's settings.
